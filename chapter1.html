Write the answers to the following questions

a. What is a computer?

Ans:- A computer is an electronic device that accepts data, processes it according to

instructions, stores it, and produces meaningful information.

b. Define the working system of a computer with block diagram.

Ans: A computer works on the IPOS cycle:

Input

Processing

Output

Storage

Block Diagram

Input → Processing → Output ↓ Storage

c. What is processing?

Ans:- Processing is the step in which a computer works on the input data to convert it into meaningful information.

d. Why is a computer called diligent machine?

Ans:- A computer is called a diligent machine because it can work continuously for a long time

without getting tired, bored, or losing accuracy.

e. Describe the features of a computer.

Ans:- Some important features of a computer are:

It Works very fast.

Computer gives 100% correct results if proper data is entered.

Computer work continuously without tiredness.

Computer can perform many different tasks.

It can store a large amount of data.

f. List out the different application areas of a computer.

Ans:- The different application areas of a computer are:

Education

Banking

Hospitals and health sector

Business

Communication

Science and research

Entertainment

Offices and industries

g. Write the merits and demerits of the computer system.

Ans:- Merits(Advantages)

It performs millions of calculations in fractions of a second.

It store huge amount of data.

It never get tired.

It gives an always accurate result.

Demerits (Disadvantages)

It cannot learn by itself.

It needs instruction to work.

It doesn’t have thinking capacity.

It doesn’t have its own IQ.

h. Why is a computer called an IPM machine?

Ans:- A computer is called an IPM machine because it works in three main steps:

Input

Process

Output

Storage

(Usually written as IPOS: Input, Process, Output, Storage.)

i. Why is a computer called a versatile machine?

Ans:- A computer is called a versatile machine because it can perform different types of tasks in various fields such as education, banking, hospitals, business, and entertainment.
