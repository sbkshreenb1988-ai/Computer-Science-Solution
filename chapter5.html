8. Very Short Answer Questions

a. What is desktop in Windows? Ans:- The desktop is the main working area of Windows.

b. What is an icon? Ans:- An icon is a small picture representing a file, folder, or program.

c. What is taskbar? Ans:- The taskbar is a horizontal bar usually found at the bottom of the desktop.

d. What is pointer? Ans:- A pointer is a small symbol that moves according to the movement of the mouse.

e. What is a window? Ans:- A window is a rectangular area on the screen where a program or file is displayed.

f. What is a folder? Ans:- A folder is a container used to store and organize files and subfolders.

g. How many folders can you create in Windows? Ans:- We can create many folders in Windows, depending on the available storage space.

h. How do you change the settings of Windows? Ans:- We can change Windows settings through the Settings app or Control Panel.

i. Where are deleted files stored? Can they be restored again? Ans:- Deleted files are stored in the Recycle Bin. Yes, they can be restored before permanent

deletion.

9. Answer the following questions

a. What is an operating system? Give some examples.

Ans:- An operating system is system software that controls and coordinates overall activities of

the computer system. Examples of windows operating systems are:- Windows, Linux, and

mac OS.

b. Write any four features of the Windows operating system.

Ans:- Any four features of Windows operating systems are:

It has a Graphical User Interface (GUI).

It supports multiple users.

It supports printers, scanners, and other hardware.

It provides various built in application accessories and programs.

c. Why is an operating system important in a computer system?

Ans:- An operating system is important because it controls the computer's hardware and

software and helps the user operate the computer easily.

d. What is the use of the desktop in Windows?

Ans: - The desktop is the main working area of Windows. It is used to access files, folders,

programs, and other computer features.

e. What is a screen saver? What is the use of a screen saver?

Ans: - A screen saver is a feature that activates a visual display after a set period of user

inactivity. It helps make the screen look attractive and provides privacy by displaying a

screen when the computer is idle.

f. What is Control Panel? What is the use of Control Panel?

Ans:- The Control Panel is a part of Windows used to view and change different system settings.

It is used to change settings for devices, users, date and time, display, and other system options.

g. Write down the key features of Control Panel.

Ans: - Some key features of Control Panel are:

It allows us to change system settings.

It helps manage hardware and devices.

It allows us to manage user accounts.

It helps change date, time, and display settings.
