8. Answer the following questions

a. What is computer hardware? Give some examples. Ans:-Computer hardware refers to the physical parts of a computer system that can be seen and touched. Examples: Keyboard, Monitor, CPU, Mouse, Printer.

b. What is computer software? Give some examples. Ans:- =Computer software is a set of programs and instructions that tells the computer what to do. Examples: Windows, MS Paint, Photoshop, Google Chrome.

c. What is input hardware? Give some examples. Ans:- Input hardware are the devices used to enter data and instructions into the computer. Examples: Keyboard, Mouse, Scanner, Microphone.

d. What is processing hardware? Give some examples.

Ans:- Processing hardware refers to the hardware that processes data and instructions in a computer system. Examples: CPU, ALU, CU, Register.

e. What is output hardware? Give some examples.

Ans:- Output hardware are the devices that display or produce the final result after processing data. Examples: Monitor, Printer, Speaker, Projector.

f. What is computer memory? Write down its importance.

Ans:- Computer memory is the storage area of a computer used to store data, instructions, and information.

Importance of computer memory are:

- It stores data and instructions for processing.

- It helps the computer work faster and efficiently.

- It stores processed results for future use.

g. What is system software? Write its two features.

Ans:- System software is the software that controls and manages the overall operations of a computer system.

Its two features are:

- It controls computer hardware and software resources.

- It provides a platform for application software to run.

h. What is application software? Write its two features.

Ans:- Application software is software designed to perform specific tasks for users.

Its two features are:

- It i.s user-oriented software.

- It performs specific tasks like drawing, typing, or calculations.

i. What is web-based software? Write its two features.

Ans:- Web-based software is software that runs through the internet using a web browser.

Its two features are:

- It can be accessed from anywhere with internet connection.

- It does not need installation on every computer.
